1. 適用

本規約は、本アプリの利用に関する運用者と利用者との間の一切の関係に適用されます。利用者が所属する学校・教育委員会等の規程がある場合、利用者はそれらにも従うものとします。

2. 提供内容

本アプリは、教職員の週案作成・時数管理・タスク管理・単元計画・学級通信作成・行事予定管理・Google Classroom 連携等を支援するツールを、無償かつ現状有姿（as is）で提供します。運用者は、本アプリの完全性・正確性・有用性・特定目的への適合性、および継続的な提供を保証しません。

本アプリは Google Apps Script 上で動作し、Google の各種サービスに依存します。Google のサービス仕様変更・障害・提供終了により、本アプリの一部または全部が利用できなくなる場合があります。

3. 利用条件

  • 本アプリの利用には Google アカウントが必要です。Google の各サービスの利用規約も併せて適用されます。
  • 本アプリは、利用者自身または所属機関が Google Apps Script プロジェクトとして導入・デプロイして利用することを前提としています。導入作業および運用は、導入者の責任で行ってください。
  • 所属機関が管理する Google Workspace アカウントで利用する場合は、事前に管理者の許可を得てください。
  • 初回利用時には、本アプリが必要とする権限（OAuth スコープ）への同意が必要です。権限の範囲と目的はプライバシーポリシーに記載しています。

個人情報を入力する場合、利用者は個人情報の保護に関する法律、所属機関の情報セキュリティポリシー、その他の関係法令・規程を遵守するものとします。運用者はこれらのデータを取得せず、その取り扱いについて責任を負いません。

6. 生成AI 機能の利用

  • 生成AI（Gemini API 等）を用いる機能は任意です。利用者が API キーを設定した場合にのみ動作します。
  • この機能を利用する場合、対象の PDF やテキストが AI 提供者のサービスへ送信されます。送信内容と、当該 AI 提供者の利用規約・プライバシーポリシーの確認・遵守は、利用者自身の責任で行ってください。

  • 秘密情報や個人情報を AI へ送信するかどうかは、所属機関の規程に従って判断してください。
