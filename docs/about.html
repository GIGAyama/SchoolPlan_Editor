週案エディタ（School Plan Note）

小学校・小中学校の先生のための、週案づくりと校務支援の Web アプリです。
Google スプレッドシートを保存先に使い、生成AI で入力の手間を減らします。

アプリを開く 導入方法（GitHub）

アプリの利用には Google アカウントでのログインが必要です。このページはログインなしでご覧いただけます。

1. どんなアプリか

週案（週間指導計画）の作成は、毎週まとまった時間がかかる仕事です。本アプリは、その入力をブラウザ上のグリッドで手早く行えるようにし、時数の集計・タスク管理・学級通信づくり・行事予定の取り込みまでを 1 つの画面にまとめたものです。

データの保存先は、先生ご自身の Google スプレッドシートです。専用のサーバーはなく、運用者が入力内容を預かることもありません。学校や自治体のアカウントでそのまま使えます。

Google Apps Script 上で動く無償のオープンソースソフトウェア（MIT License）です。

2. できること

画面上部の 8 つのタブを切り替えて使います。

タブ 何をする画面か
週案 1 週間分の予定をグリッドに入力します。ドラッグ＆ドロップでのコマ移動、祝日の自動表示、週をまたいだ全文検索、A4 での印刷に対応しています。
行事予定 学校の年間行事予定 PDF を登録して閲覧します。
タスク 準備物や連絡事項を管理します。期日が近いものを毎朝メールで受け取ることもできます（任意）。
単元 年間指導計画にあたる「単元マスタ」を表形式で編集します。
学級通信 学級通信をブロックエディタで作り、PDF 出力や Google Classroom への投稿ができます。
時数 教科別の実施時数を集計し、年度末の過不足を見通します。
PDF読み込み 指導計画や行事予定の PDF を生成AI で解析し、確認画面を経てから取り込みます。
設定 固定時間割、標準時数、データの保全・復元などを設定します。

3. 必要な権限と、その理由

初回のログイン時に、Google から許可を求められます。求める権限は機能に必要な範囲だけで、いずれも先生ご自身のデータに対する操作です。運用者へ送信されるものはありません。

権限 何に使うか
userinfo.email ログイン中の先生を見分け、先生ごとにデータを分けるため。
spreadsheets 週案データベースとなるスプレッドシートの読み書き。
drive.file アプリが作ったファイルと、先生が選んだファイルだけを扱います。ドライブ全体は見ません。
script.scriptapp PDF 解析のバックグラウンド実行や、リマインダーの定時実行に使うトリガーの作成・削除。
script.external_request 生成AI（Gemini API）への問い合わせと、Classroom の資料取得。
script.send_mail タスクのリマインダーを先生ご本人宛に送るため。有効にした場合のみ動きます。
classroom.courses.readonly Classroom 連携を使う場合のみ、担当クラスの一覧・資料を取得します。
classroom.announcements Classroom 連携を使う場合のみ、ご自身のクラスへお知らせを投稿します。

詳しい説明はプライバシーポリシーに記載しています。許可はあとから Google アカウントの設定でいつでも取り消せます。

4. データの取り扱い

要点

  • 入力したデータは先生ご自身の Google アカウント内にのみ保存されます。
  • 運用者は、そのデータを受け取らず、保存せず、閲覧しません。運用者側のサーバーはありません。
  • 広告や行動追跡のための Cookie は使用していません。

生成AI に文章や PDF を送るのは、先生が API キーを設定し、その機能を実行したときだけです。API キーは先生ごとに分離された領域に保存され、運用者は取得しません。

くわしくはプライバシーポリシーと利用規約をご覧ください。

5. 使いはじめるには

本アプリは、先生ご自身または学校が Google Apps Script のプロジェクトとして導入して使います。導入手順は GitHub リポジトリの README にまとめています。

  • GitHub リポジトリ（導入手順・ソースコード）
  • すでに導入済みの場合は、アプリを開くからご利用ください。
  • スマートフォンやタブレットでは、ブラウザの「ホーム画面に追加」でアプリのように全画面で使えます。

学校が管理する Google Workspace アカウントで使う場合は、事前に管理者の許可を得てください。

ホーム画面に追加する

次の手順で、アプリのように全画面で使えるようになります。

  1. 1 下の「アプリを開く」を押して、アプリの画面に移ります。
    ホーム画面に載せるのは、この紹介ページではなくアプリの画面です。
  2. 2 Safari の共有ボタン をタップします。
    iPhone は画面下、iPad はアドレスバーの右上にあります。
  3. 3 メニューから「ホーム画面に追加」→ 右上の「追加」を押すと完了です。
  1. 1 下の「アプリを開く」を押して、アプリの画面に移ります。
  2. 2 ブラウザのメニュー（︙）から「アプリをインストール」を選びます。
    パソコンではアドレスバーの右端にインストールのアイコンが出ることもあります。
  3. 3 「インストール」を押すと完了です。
